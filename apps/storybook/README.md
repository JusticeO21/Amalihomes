# 📖 Storybook - Amali Homes

This is the **Storybook app** for the Amali Homes monorepo. It showcases and documents reusable UI components from the shared `@repo/ui` package.

---

## 🚀 Getting Started

```bash
cd apps/storybook
pnpm install
pnpm storybook
```

---

## 📁 Folder Structure

```
apps/storybook/
├── .storybook/         # Storybook config files
├── src/stories/            # Component stories
```

---

## 📦 Useful Commands

| Command      | Description                 |
| ------------ | --------------------------- |
| `pnpm dev`   | Start Storybook dev server  |
| `pnpm build` | Build Storybook static site |
